# Dalnice (mobilni verze)

Kivy/Android port hry Dalnice.

## Jak ziskat .apk

Po kazdem pushnuti do vetve `main` se automaticky spusti GitHub Actions build
(viz zalozka **Actions** nahore na GitHubu). Az build dobehne (trva cca 15-25 minut
poprve), otevri posledni beh workflow "Build Android APK" a dole v sekci
**Artifacts** najdes `dalnice-apk` – to je zip s hotovym `.apk` souborem ke stazeni
a instalaci na telefon (Nastaveni -> povolit instalaci z neznamych zdroju).

Build take muzes spustit rucne tlacitkem **Run workflow** v zalozce Actions.
